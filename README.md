## 有限状态树
    本项目是一个有限状态树。用于游戏的场景和界面管理时，比普通的有限状态机强大许多。

## 特点
1. 状态树上每个节点都是一个状态。
2. 同时激活的状态是一条从树根开始到任意节点的一条激活线上的所有状态。
3. 激活线上，除了根节点的另一端的节点叫做激活目标节点。
4. 状态切换的过程就是激活目标节点改变的过程。
5. 从状态A切换到状态B的过程
   1. 找到状态A和状态B的公共节点。比如公共节点是C（C也可能是A或者B中的一个）
   2. 在[A,C)上调用 OnPrepareExit
   3. 在C上调用 OnPrepareSwitch
   4. 在(C,B]上调用 OnPrepareEnter （这一步在A和B存在父子节点关系时没有）
   5. 在[A,C)上调用 OnExit
   6. 在C上调用 OnSwitch
   7. 在(C,B]上调用 OnEnter （这一步在A和B存在父子节点关系时没有）
   8. 完成切换
